# ShopWave

ShopWave is an e-commerce web application built to make online shopping simple and easy to use. Users can browse products, explore different categories, search for products, and manage their shopping cart through a responsive interface.

## Features

- Browse and view products
- Explore products by category
- Search and filter products
- View product details
- Add and manage products in the shopping cart
- User authentication
- Responsive design for desktop and mobile devices
- Supabase database integration
- Environment variables for storing configuration securely

## Technologies Used

### Frontend

- React
- TypeScript
- HTML5
- CSS3
- Tailwind CSS
- Vite

### Backend and Database

- Supabase
- PostgreSQL
